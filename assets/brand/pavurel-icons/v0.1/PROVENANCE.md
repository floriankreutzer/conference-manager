# Icon provenance and rights

The six `light` originals (`request`, `participants`, `room-equipment`, `catering`,
`changes`, `coordination`) are byte-identical to
[Website commit e34cb7c2b039f92e2c054711c55a9125c0645d86](https://github.com/floriankreutzer/conference-manager-website/tree/e34cb7c2b039f92e2c054711c55a9125c0645d86/public/assets/icons).
Their original Git blob identities were verified; the
[manifest](../../../../docs/brand-reference/pavurel-icons/v0.1/manifest.json)
retains immutable file URLs and SHA-256 values. The source README records the
six original line icons and owner approval for Website use on 19 October 2026.
That historical approval is not asserted to be a general public reuse license.

The 26 additional motifs are original simple SVG geometry drawn for the
27 October 2026 Conference Manager task. Mono and inverse variants preserve the
light geometry with controlled stroke colors. No Lucide, Heroicons or other
library artwork is claimed or imported. No public icon license/SPDX identifier
was found in the cited source, and this draft does not assign one. Font licenses
in another repository do not automatically license these icons.

Microsoft third-party branding is held separately. Pavurel signet geometry is
not part of this functional set. The shared asset reference changes neither
product architecture nor release status. Review of the draft and repository
storage do not establish live usability/accessibility acceptance.
