# Pavurel functional icons v0.1

Working draft for shared Website, Customer and Platform use: **32 motifs, three
variants, 96 SVG files**. These files are stored as the canonical GitHub asset
source; they are not integrated into a view or accepted as a live UI.

Follow the [canonical icon contract](../../../../docs/ICON-SYSTEM.md), current
repository tokens and native presentation conventions. `light/` uses Ink and one
Bordeaux accent, `mono/` uses `currentColor`, and `inverse/` uses white. All share
24 by 24 geometry, unfilled 1.6 strokes and round caps/joins. An external `img`
does not inherit `currentColor` from its surrounding HTML.

Text carries the action and state. Icons do not confer permissions or prove health,
delivery, measurement, audit integrity or recovery. Decorative use must not add
redundant announcements; informative use needs localized accessible names and
unique inline IDs. The English standalone title/description IDs must not be
copied repeatedly into one document without deliberate handling.

Six light files are byte-identical Website originals; 26 motifs are new original
vectors for this draft. No third-party icon library, Microsoft logo, Pavurel
signet, new framework or runtime package is part of this functional set. No public
MIT/SPDX license is assigned. Reference material stays outside `assets/` because
Customer packaging includes every non-Markdown file in that directory.
