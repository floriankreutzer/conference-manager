# Brand review material

This directory holds documentation/reference material outside automatically
packaged browser assets. The canonical payloads and entry points are under
[assets/brand](../../assets/brand/README.md); usage follows [ICON-SYSTEM.md](../ICON-SYSTEM.md).

- [Pavurel functional icon draft v0.1](pavurel-icons/v0.1/README.md): original
  manifest/semantic CSV, contact sheet, dated validation and offline reproduction.
- [Microsoft sign-in reference](microsoft-sign-in/reference-2026-10-27/README.md):
  original third-party manifest/hashes/redlines and a labeled reference preview.

These are review assets, not screenshots of an integrated or deployed product.
They do not add a runtime loader or modify authorization, feature flags, the
Platform inventory, CSP, the Customer builder or the protected API asset reader.
